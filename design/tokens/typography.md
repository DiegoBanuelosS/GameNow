## Typography tokens

- Font family: `Sora`, `Segoe UI`, `sans-serif`
- Base size: `16px`
- Line height: `1.5`

### Roles

- `heading-xl`: 28px / 1.2 / 600 – page titles (one per page)
- `heading-m`: 22px / 1.25 / 600 – section titles
- `body`: 16px / 1.5 / 400 – form copy and actions
- `body-small`: 14px / 1.45 / 400 – helper text and secondary links
- `caption`: 13px / 1.4 / 500 – field labels
